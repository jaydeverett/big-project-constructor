# Privacy

Big Project Constructor is a set of instructions and templates. It is not a service.

- **It collects nothing.** There is no server, no account, no analytics, and no network call of any kind. The one script it ships, an optional wrap-up reminder, runs only if you turn it on, writes only to a temporary directory on your own computer, and never touches the network.
- **Your project stays where you put it.** The files it creates live in a folder on your computer (Claude Code, Codex) or in your own ChatGPT Project (ChatGPT on the web). Nothing is sent to the author.
- **The assistant you run it in has its own policy.** What Claude or ChatGPT reads and writes while helping you is handled under Anthropic's or OpenAI's privacy policy, exactly as it would be without this plugin.

Questions: open an issue at https://github.com/jaydeverett/big-project-constructor/issues.
